# Contexto - homelab-observabilidad-seguridad

Ficha de lectura rapida: que es, por que existe y que muestra.

## 1. Que es

Metricas, dashboards, alertas y SIEM de un homelab, y un caso extenso de controles automatizados que informaban algo distinto de la realidad.

## 2. Por que existe

Es parte de un portfolio tecnico para entrevistas: muestra criterio y
experiencia sobre un entorno real sin exponerlo. El entorno original es
privado; este repo es su version transformada.

## 3. Que muestra

- Alertas que solo avisan de fallos reales
- Metricas de infraestructura separadas de evidencia de seguridad
- Verificar el efecto de un control, no la accion
